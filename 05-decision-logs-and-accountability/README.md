# 05 · Decision logs and accountability

The accountability layer: who decided what, based on which evidence, under which assumptions and with which known risks.

## Why a decision log

AI-supported work changes faster than policies. Without a record, nobody can say later why a tool was allowed for one task and not for another, who checked the data question, or when the decision should be looked at again.

A decision log keeps that record short and findable. One entry per decision, written when the decision is made, not reconstructed afterwards.

## How to use it

1. Write the entry before the use case goes live, together with the person who owns the workflow.
2. Keep evidence as links, not copies. Never paste personal data or confidential content into the log.
3. Set a review date. A decision without a review date becomes a permanent rule by accident.
4. When something goes wrong, add to the entry instead of starting a new one, so the history stays in one place.
